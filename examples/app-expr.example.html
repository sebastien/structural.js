Expression Editor

Structural blocks for arithmetic expressions. Mod+A selects the current unit and expands outward; Mod+Shift+A contracts. Enter an empty slot to open the chooser — Enter confirms, Esc closes, Del clears the selected unit. Select an operator to change it. Type + − * / at the end of a unit to extend after, or at the start (or Shift+op) to extend before.
