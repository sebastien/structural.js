# Rules

Selection & Movement:
- Add a space moves the cursor
- Multiple spaces swallowed unless in preformatted mode
- Ctrl-A selects the current block
- Subsequent Ctrl-A expand the selection, Shift-Ctrl-A contract.
- Ctrl-Shift-{Left,Rigth,Up,Down} expand the selection in the given direction
- Ctrl-C copies the selection
- Ctrl-V pastes the selection
- Ctrl-V over a selected text when clipboard has url converts selection to link


Common shortcuts:
- Ctrl-b: toggle bold
- Ctrl-i: toggle italic
- Tab: indent
- Shift-Tab: dedent
